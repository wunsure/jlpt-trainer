# 日本語瞬発力

JLPT N1 練習網站。開啟 `index.html` 即可練習，也可以用 GitHub Pages 從 `main` 的根目錄發佈。網站不需要安裝套件或建立帳號。

- **假名詞彙（153 題）**：兩份複習 PDF 共 163 條，合併 10 條重複。保留來源分類、異體表記及詞義相異的同音詞；同音題附語境。
- **擬聲擬態詞（200 題）**：按情緒、身體、聲音等主題整理，搭配自編例句和繁體中文釋義。
- **核心語法（52 題）**：保留上傳的 Top50 CSV 內實際收錄的 52 個文法條目，使用句子填空題。

每輪從所選題庫抽出 50 題，每題 10 秒。前四個選項隨機排列，第五個固定為「不知道／完全沒有印象」。可點擊選項或按數字鍵 1–5。作答或超時後顯示正解並自動進入下一題。

完成的練習會存到目前瀏覽器的本機儲存空間。學習檔案可以按題庫查看分數、作答明細和反應時間，錯題複習會收錄答錯、不知道及超時的項目。累積複習依各題最近一次完成的作答狀態更新。
